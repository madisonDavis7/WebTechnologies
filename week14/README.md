# Reflection Stuff #

I think working in 3D was a learning experience because I have a hard time designing things and thinking about them in 3D. I have struggled with 3D concepts in previous game classes and don't have a ton of experience coding with it. I think the most important thing I learned was to sit down and use paper to kind of plan out all the aspects I would need to cover. Having a plan was helpful and let me stay more organized and not get so overwhelmed. In terms of the code itself I think it was really beneficial getting a better grasp about how the camera and objects are connected. There were a lot of times that I had the object working fine but couldn't see it cause I had messed up the camera or soemthing. It's harder to program things in 3D in my opinion and the camera is a major part of that. The most challenging thing to me was getting my imports and links to resources to work. I had a hard time getting my project to read my scripts and external links and had to get help from the internet and ai to get those resolved. I ended up having to use an import map because I was getting errors that the browser couldn't read 'three' and this was how I resolved that. It was frustrating but cool to see imports in this way. I used ai because I wanted to be able to get possible solutions, understand why I was getting an error, and be walked through how to fix it. I've found that ai is a good way to have error messages explained and get walked through the steps to fix it. For my project I wanted to do something space for sure. When I think of 3D rotating objects I automatically think of planets, so I went with that. I thought having a cube moon would be a cool way to add in another shape and make it more fun. The robot wasn't my first pick but I was having a hard time finding models to use that would work and this was the first one I got to work so I just stuck with it. If I had more time to dedicate to this project I would get rid of the robot and add in a satellite or space station of some sorts. I added in some camera movement to kinda mimick an astronaut floating in space so haing a spaceship or station in the distance would go with my lost in space vibes. I wanted to add a shooting star or asteroid but didn't have the time or energy so that could be another neat thing to add one day. Music would also be fun, kinda make the scene complete. I definitely want to expand upon this scene in the future when I have enough time to dedicate to it.
